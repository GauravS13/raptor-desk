How these numbers are made

Each judge's latest review of each project is turned into one weighted score. The additive model then estimates every project's quality and every judge's leniency together, so a project is not rewarded for drawing generous judges. A judge who gave identical scores everywhere is left out of the fit. The 90% interval and the chance of finishing inside each prize cutoff come from {{ params.bootstrap|floatformat:0 }} bootstrap resamples (seed {{ params.seed|floatformat:0 }}). Parameters: shrinkage k = {{ params.k }}, ridge λ = {{ params.lambda }}. Full method: JUDGING.md.
